# `benchmarks/hd209`: the HD 209458 b wind the Ly-alpha coupling reads

## Configuration of record, 2026-09-06

**Purpose of this directory.** The HD 209458 b benchmark wind that the LaRT
Monte Carlo Ly-alpha coupling is built from (`lart_runs/bm_hd209/`,
`insitu_hd209/`), together with the in-situ emissivity products stored here
(`insitu_emiss.txt`, `insitu_emiss.png`, `insitu_lum.txt`) and the paper
transit curves `paper_tpm_{Halpha,He10830,Lya}.txt`. It carries its own
1 microbar `base.inp` and its own three-element `metals.inp` (C, N, O).

**Reference model it is compared with.** The stellar spectrum follows
Oklopcic and Hirata (2018), ApJL 855, L11 (`2018ApJ...855L..11O`), section
3.1, as the planet folder does. This is NOT the same model as
`HD209458b/`: here `He_diffusion: True`, `He_metal_diffusion: True`,
`He_Kzz: 1.0e9` and there is no `Jlya escape-prob`, while `HD209458b/` has the
escape-probability closure and no diffusion.
`docs/paper_materials_vintage_audit.md` section 3c measures the two at
`log10 Mdot` 10.40 against 9.47, a difference of 0.93 dex.

**The spectrum in force until this switch.** READ from `input.inp` as it stood
on 2026-09-06:

```
Spectrum type: Power-law
Power-law index: -1.0
[E_low,E_mid,E_high] = [ 13.60 , 123.98 , 1.24e3 ]
Log10 of X-ray luminosity [erg/s]: 27.20
Log10 of EUV luminosity [erg/s]: 27.93
```

A single power law `F_E ~ E^-1` normalized on `[13.60, 1.24e3] eV` from those
two luminosities at `a = 0.0480 AU`, and, because one spectrum type builds
every band, the SAME power law extrapolated below 13.6 eV down to the
photon-grid floor, which the H(n=2) Balmer edge sets at 3.3996 eV here
(`Stellar Teff [K]: 6065` and `Stellar radius [R_sun]: 1.155` are both
positive).

**Every output directory present was produced under that power law.** None is
regenerated by this switch and none is deleted. MEASURED mtimes, 2026-09-06:

| directory | mtime |
|---|---|
| `output/` | 2026-08-15 19:04 |
| `output_pre_kb_20260815/` | 2026-08-15 18:40 |
| `output_pre_xuvfix/` | 2026-08-09 09:36 |

The stored `insitu_*` products and the `paper_tpm_*` curves descend from
`output/`, so they too are power-law products.

## The spectrum switched in, 2026-09-06 (PLAN rev 2, step C3)

```
Spectrum type: Load from file..
Spectrum file: ../../inputdata/sed/hd209458b_solar_whi2008.txt
```

Two levels of `..`, because this run directory sits one level deeper than a
planet folder and the binary resolves the path relative to the working
directory it is started in. `Power-law index` is gone: `input_read.f90`
consumes that line only under `Spectrum type: Power-law`.
`Log10 of X-ray luminosity` and `Log10 of EUV luminosity` are mandatory lines
and stay, but **their values no longer set anything**: `read_sed` integrates
the photon grid it builds from the file and overwrites `LX` and `LEUV` with
the result, splitting the two bands at `e_mid`. A comment line above them says
so (the parser skips blank and `#` lines).

**File and checksum.** `inputdata/sed/hd209458b_solar_whi2008.txt`, SHA-256
`e4b8762e74e7f9d4e9036c193dd88d8c252b5f5f2ce1bf9c5a614541af5f4591`. It is the
same file the planet folder `HD209458b/` now names, as it must be: one planet,
one spectrum.

**Coverage.** 5000 rows, 0.5000 to 4999.5 A, strictly increasing, no negative
flux; bin-averaged on 1 A bins.

**Units at the orbit.** Column 1 wavelength in A, column 2 `F_lambda` at the
planet in erg cm^-2 s^-1 A^-1. MEASURED band fluxes at the orbit:
F(1-912 A) = 1.3405e3, F(10-912 A) = 1.3398e3, F(912-2600 A) = 1.1943e6
erg cm^-2 s^-1; F(10-912 A) is the band a run actually integrates.

**Normalization and distance, READ from the file header.** WHI 2008 solar
reference spectrum (Woods et al. 2009), column "March 30 - April 4 (6-day
average)", at 1 au, scaled by `(1 au / a)^2 = 451.348084` with
`a = 0.04707 AU`, no stellar-radius correction. The file's 0.04707 AU is the
Oklopcic and Hirata value, and since 2026-09-06 this input states
`Orbital distance [AU]: 0.04707` as well (it stated 0.0480 before; the
reference paper fixes the distance, as for HD 189733 b), so irradiation and
gravity use one distance; see `HD209458b/README.md`.

**Active absorbers and the grid floor.** He 2^3S on (`Include He23S? True`);
H(n=2) armed by `Stellar Teff [K]: 6065` and `Stellar radius [R_sun]: 1.155`;
three trace metals from this directory's own `metals.inp` (C, N, O). The
lowest threshold is the H(n=2) Balmer edge at 3.3996 eV = 3647.0 A, so the
photon grid runs 3.3996 to 1240 eV. The file reaches 4999.5 A.

**Dayside dilution.** `2D approximate method: Rate/2 + Mdot/2`, so every
stellar beam is multiplied by 0.500.

**Coverage check.** `sed_coverage_and_order_check.py` carries the file rules
and the band fluxes of this file (exit 0, MEASURED 2026-09-06) but has NO
configuration entry for `benchmarks/hd209`; its per-configuration coverage
table lists `HD209458b`, which states the same floor (H(n=2), 3647.0 A) and
names the same file:

```

PASS HD209458b:named:hd209458b_solar_whi2008.txt:rows_in_window measured=3637 reference=>=2 in [9.9987,3647.0] A tol=exact
```

**Consumer check on the binary.** A two-step run (`EXHALE_MAXSTEPS=2`) of a
scratch copy of this directory, MEASURED 2026-09-06, setup report:

```
 - Log EUV luminosity: 27.903 [erg/s]
 - Log X-ray luminosity: 26.842 [erg/s]
 - Log XUV flux at the planet distance: 3.127 [erg/(cm^2 s)]
 - Including helium triplet chemistry
 - Including 3 trace metal element(s)
  - Spectrum read from external file: ../../inputdata/sed/hd209458b_solar_whi2008.txt
 - Spectrum type: Load, and it builds every band of the photon grid
   Below 13.6 eV (down to   3.40 eV): the same SED file as every other band.
   Integrated grid flux sum(F dE) =  1.5147E+07 erg cm^-2 s^-1 (after the dilution)
     against the nominal (10^LX + 10^LEUV)/(4 pi a^2) =  6.7023E+02 at the same dilution: ratio ********
 - Dayside dilution applied to every stellar beam:  0.500
```

`read_sed` accepts the file at this configuration's 3.40 eV floor. The
"nominal" line is the recomputed XUV band alone at the dilution; the printed
`1.5147E+07` is the whole grid down to 3.40 eV, dominated by the solar
near-ultraviolet, so the overflowed ratio is not a mismatch. `log F_XUV` at
the orbit goes from 3.193 (the power law, from the `LX = 27.20`,
`LEUV = 27.93` this file used to carry) to 3.127, a factor 0.860.

**Reruns are a separate instruction.** Nothing here was re-run, re-converged
or deleted, and neither the LaRT cases built from `output/` nor the
`insitu_*` products were touched. Producing a wind under this input is a
D-physical step of `docs/PLAN_20260906_rev2.md` section 3, gated on its own
prerequisites and on an explicit instruction.
