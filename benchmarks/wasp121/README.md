# `benchmarks/wasp121`: the WASP-121 b wind the Ly-alpha coupling reads

## Configuration of record, 2026-09-06

**Purpose of this directory.** The WASP-121 b benchmark wind that the LaRT
Monte Carlo Ly-alpha coupling is built from (`lart_runs/bm_wasp121/`,
`insitu_wasp121/`), together with the in-situ emissivity products stored here
(`insitu_emiss.txt`, `insitu_emiss.png`, `insitu_lum.txt`) and the paper
transit curves `paper_tpm_{Halpha,He10830,Lya}.txt`. It carries its own
`base.inp` and NO `metals.inp`, so it runs metals-off.

**Reference model it is compared with.** Huang, Koskinen, Lavvas and
Ben-Jaffel (2023), ApJ 951, 123 (`2023ApJ...951..123H`): its Table 1 supplies
`R_p = 2.2075 R_J`, `M_p = 1.1824 M_J`, `a = 0.02544 au`, `T_eff = 6459 K`
and `R_star = 1.458 R_sun`, its section 2.2 the
`F_XUV = 1.6e6 erg cm^-2 s^-1` normalization and the
`1.0e5 erg cm^-2 s^-1` Ly-alpha line flux. This is NOT the same model as
`WASP-121b/`: here `Include He23S? False`, `Deexc heat: True`, metals off and
no transonic initial condition.

**The spectrum in force until this switch.** READ from `input.inp` as it stood
on 2026-09-06:

```
Spectrum type: Power-law
Power-law index: -1.0
[E_low,E_mid,E_high] = [ 13.60 , 123.98 , 1.24e3 ]
Log10 of X-ray luminosity [erg/s]: 29.46
Log10 of EUV luminosity [erg/s]: 30.42
```

A single power law `F_E ~ E^-1` normalized on `[13.60, 1.24e3] eV` from those
two luminosities at `a = 0.02544 AU`, and, because one spectrum type builds
every band, the SAME power law extrapolated below 13.6 eV down to the
photon-grid floor. `Include He23S?` is False here, but `Stellar Teff [K]:
6459.0` and `Stellar radius [R_sun]: 1.458` are both positive, so H(n=2) is
armed and the floor is still the Balmer edge at 3.3996 eV.

**Every output directory present was produced under that power law.** None is
regenerated by this switch and none is deleted. MEASURED mtimes, 2026-09-06:

| directory | mtime |
|---|---|
| `output/` | 2026-08-15 18:43 |
| `output_pre_kb_20260815/` | 2026-08-15 18:40 |

The stored `insitu_*` products and the `paper_tpm_*` curves descend from
`output/`, so they too are power-law products.

## The spectrum switched in, 2026-09-06 (PLAN rev 2, step C3)

```
Spectrum type: Load from file..
Spectrum file: ../../inputdata/sed/wasp121b_composite_huang2023.txt
```

Two levels of `..`, because this run directory sits one level deeper than a
planet folder and the binary resolves the path relative to the working
directory it is started in. `Power-law index` is gone: `input_read.f90`
consumes that line only under `Spectrum type: Power-law`.
`Log10 of X-ray luminosity` and `Log10 of EUV luminosity` are mandatory lines
and stay, but **their values no longer set anything**: `read_sed` integrates
the photon grid it builds from the file and overwrites `LX` and `LEUV` with
the result, splitting the two bands at `e_mid`. A comment line above them says
so (the parser skips blank and `#` lines).

**This file is PROVISIONAL.** It is candidate C of step C2: the solar (WHI
2008) XUV shape below 1700 A at the Huang et al. `F_XUV = 1.6e6`
normalization, and the bolometrically scaled WASP-17 (F6V, MUSCLES v24)
photosphere above 1700 A as a proxy for WASP-121, with NEITHER component
renormalized to close the join (MEASURED step
`f(1700.0 A)/f(1699.5 A) = 0.1324`). It is not a reproduction of the Huang et
al. spectrum. The sensitivity inputs are candidate A
`wasp121b_solar_huang2023.txt` (SHA-256
`e504432bc16e51f8944a19c76be07db7de85b2f8dc2d484614c6460ab88e830a`) and
candidate B `wasp121b_wasp17_huang2023.txt` (SHA-256
`1e20037210a908cd6ef7aba27331bb3800bd3fdf106b7ccc5bff62e7913bdc02`); either is
a one-line change of the `Spectrum file:` value, and the C2 report holds the
measured A/B/C rate comparison.

**File and checksum.** `inputdata/sed/wasp121b_composite_huang2023.txt`,
SHA-256 `92cc4fdf4b44556e066b5dc077b69a252cc8369f6b13f247105cc31b19687baa`. It
is the same file the planet folder `WASP-121b/` now names.

**Coverage.** 5001 rows, 0.5000 to 5000.0 A, strictly increasing, no negative
flux; bin-averaged on 1 A bins throughout.

**Units at the orbit.** Column 1 wavelength in A, column 2 `F_lambda` at the
planet in erg cm^-2 s^-1 A^-1. MEASURED band fluxes at the orbit:
F(1-912 A) = 1.6000e6, F(10-912 A) = 1.5992e6, F(912-2600 A) = 1.028e8
erg cm^-2 s^-1; F(10-912 A) is the band a run actually integrates.

**Normalization and distance, READ from the file header.** Below 1700 A: WHI
2008 at 1 au times `5.387291e5` so that F(1-912 A) = 1.6000e6 at the planet,
with the Ly-alpha window 1206-1226 A above its local continuum times
`2.961511e-2` so that the line flux is 1.000e5 (both Huang et al. 2023 section
2.2). Above 1700 A: MUSCLES v24 WASP-17 at Earth times `1.206591e19` so that
the bolometric flux at the planet is
`sigma T_eff^4 (R_star/a)^2 = 7.0028e9 erg cm^-2 s^-1` with `T_eff = 6459 K`,
`R_star = 1.4572 R_sun`, `a = 0.02544 au` (Huang Table 1). The orbital
distance of the file and of this input agree at 0.02544 AU.

**Active absorbers and the grid floor.** `Include He23S? False` here, so the
metastable is NOT an absorber, and there is no `metals.inp`. H(n=2) is armed
all the same, because `Stellar Teff [K]: 6459.0` and
`Stellar radius [R_sun]: 1.458` are both positive, and it alone sets the floor
at the Balmer edge 3.3996 eV = 3647.0 A. The photon grid therefore still runs
3.3996 to 1240 eV, and the file has to reach 3647.0 A. It reaches 5000.0 A.

**Dayside dilution.** `2D approximate method: Rate/2 + Mdot/2`, so every
stellar beam is multiplied by 0.500.

**Coverage check.** `sed_coverage_and_order_check.py` carries the file rules
and the band fluxes of this file (exit 0, MEASURED 2026-09-06) but has NO
configuration entry for `benchmarks/wasp121`; its per-configuration coverage
table lists `WASP-121b`, which states the same floor (H(n=2), 3647.0 A) and
names the same file. The stricter absorber set of the planet folder does not
change the floor, since the Balmer edge is already the lowest threshold there:

```
  # WASP-121b: He23S=True Teff=6459 R=1.458 metals=C,N,O,Mg,Ca,Na,Fe
  #   required band 10.00-3647.0 A (3.3996-1240 eV); long endpoint set by H(n=2), the Balmer continuum: Stellar Teff and Stellar radius are both set; short endpoint by E_high with X-rays on
PASS WASP-121b:named:wasp121b_composite_huang2023.txt:reaches_long_endpoint measured=5000.0 A reference=>=3647.0 A tol=exact
PASS WASP-121b:named:wasp121b_composite_huang2023.txt:reaches_short_endpoint measured=0.5000 A reference=<=9.9987 A tol=exact
PASS WASP-121b:named:wasp121b_composite_huang2023.txt:rows_in_window measured=3638 reference=>=2 in [9.9987,3647.0] A tol=exact
```

**Consumer check on the binary.** A two-step run (`EXHALE_MAXSTEPS=2`) of a
scratch copy of this directory, MEASURED 2026-09-06, setup report:

```

 - Log X-ray luminosity: 29.367 [erg/s]
 - Log XUV flux at the planet distance: 6.204 [erg/(cm^2 s)]
 - Coupled equilibrium system size: N_eq = 3

 - Spectrum type: Load, and it builds every band of the photon grid
   Below 13.6 eV (down to   3.40 eV): the same SED file as every other band.
   Integrated grid flux sum(F dE) =  3.3422E+08 erg cm^-2 s^-1 (after the dilution)
     against the nominal (10^LX + 10^LEUV)/(4 pi a^2) =  7.9999E+05 at the same dilution: ratio  417.784
 - Dayside dilution applied to every stellar beam:  0.500
```

`read_sed` accepts the file at this configuration's 3.40 eV floor even with
the metastable off: the floor comes from H(n=2), and the report confirms the
grid starts at 3.40 eV. The recomputed XUV, 7.9999e5 at the 0.5 dilution, is
the file's own 1.6e6 normalization halved. `log F_XUV` at the orbit moves from
6.205 to 6.204, a factor 0.997, because the power law was already normalized
to the same `F_XUV`; what changes is the shape within the XUV and the
sub-Lyman band.

**Reruns are a separate instruction.** Nothing here was re-run, re-converged
or deleted, and neither the LaRT cases built from `output/` nor the `insitu_*`
products were touched. Producing a wind under this input is a D-physical step,
gated on its own prerequisites and on an explicit instruction.
