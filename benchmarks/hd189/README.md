# `benchmarks/hd189`: the HD 189733 b wind the Ly-alpha coupling reads

## Configuration of record, 2026-09-06

**Purpose of this directory.** The HD 189733 b benchmark wind that the LaRT
Monte Carlo Ly-alpha coupling is built from (`lart_runs/bm_hd189/`,
`insitu_hd189/`), together with the in-situ emissivity products stored here
(`insitu_emiss.txt`, `insitu_emiss.png`, `insitu_lum.txt`) and the paper
transit curves `paper_tpm_{Halpha,He10830,Lya}.txt`. It carries its own
`base.inp` and NO `metals.inp`, so it runs metals-off.

**Reference model it is compared with.** Salz et al. (2016), A&A 586, A75
(`2016A&A...586A..75S`): Table 2 supplies the orbital distance of record
`a = 0.031 AU` and Table 3 the X-ray, EUV and Ly-alpha luminosities the
spectrum is normalized to. This is NOT the same model as `HD189733b/`: here
there is no element diffusion, `Deexc heat: True` is set, and there is no
`Base grid` refinement.

**The spectrum in force until this switch.** READ from `input.inp` as it stood
on 2026-09-06:

```
Spectrum type: Power-law
Power-law index: -1.0
[E_low,E_mid,E_high] = [ 13.60 , 123.98 , 1.24e3 ]
Log10 of X-ray luminosity [erg/s]: 28.420
Log10 of EUV luminosity [erg/s]: 28.680
```

A single power law `F_E ~ E^-1` normalized on `[13.60, 1.24e3] eV` from those
two luminosities at `a = 0.031 AU`, and, because one spectrum type builds every
band, the SAME power law extrapolated below 13.6 eV down to the photon-grid
floor, which the H(n=2) Balmer edge sets at 3.3996 eV here
(`Stellar Teff [K]: 4875` and `Stellar radius [R_sun]: 0.765` are both
positive).

**Every output directory present was produced under that power law.** None is
regenerated by this switch and none is deleted. MEASURED mtimes, 2026-09-06:

| directory | mtime |
|---|---|
| `output/` | 2026-08-16 00:12 |
| `output_pre_kb_20260815/` | 2026-08-15 18:40 |
| `output_pre_lyafix/` | 2026-08-09 09:36 |

The stored `insitu_*` products and the `paper_tpm_*` curves descend from
`output/`, so they too are power-law products. Those outputs also predate the
`Orbital distance [AU]` correction from 0.0330 to 0.031 that this file now
carries.

## The spectrum switched in, 2026-09-06 (PLAN rev 2, step C3)

```
Spectrum type: Load from file..
Spectrum file: ../../inputdata/sed/hd189733b_epseri_salz2016.txt
```

Two levels of `..`, because this run directory sits one level deeper than a
planet folder and the binary resolves the path relative to the working
directory it is started in. `Power-law index` is gone: `input_read.f90`
consumes that line only under `Spectrum type: Power-law`.
`Log10 of X-ray luminosity` and `Log10 of EUV luminosity` are mandatory lines
and stay, but **their values no longer set anything**: `read_sed` integrates
the photon grid it builds from the file and overwrites `LX` and `LEUV` with
the result, splitting the two bands at `e_mid`. A comment line above them says
so (the parser skips blank and `#` lines).

**Which file, and why this one.** The Salz-normalized file is the run of
record for HD 189733 b (decision 5 of `PLAN_20260906_rev2.md` section 2),
because this wind is compared with the Salz et al. (2016) simulation. The
observed-star alternative is
`../../inputdata/sed/hd189733b_bourrier2020.txt` (SHA-256
`da76f1fd69920f6aba33fb4f5503ebec04459eca19a34dcb981d5bee2bf3a1af`), the
Bourrier et al. (2020) DEM reconstruction averaged over Visits B-E; selecting
it is the one-line change of the `Spectrum file:` value, and it raises
F(10-912 A) from 2.0430e4 to 2.7481e4 erg cm^-2 s^-1.

**File and checksum.** `inputdata/sed/hd189733b_epseri_salz2016.txt`, SHA-256
`dd0764ffadd986d969f2005ca061e4247812e7e4c48c804f663b0a43cc7b0cd4`. It is the
same file the planet folder `HD189733b/` now names.

**Coverage.** 4997 rows, 3.9392 to 4999.9392 A, strictly increasing, no
negative flux; bin-averaged on the 1 A bins of the MUSCLES const-res product.

**Units at the orbit.** Column 1 wavelength in A, column 2 `F_lambda` at the
planet in erg cm^-2 s^-1 A^-1. MEASURED band fluxes at the orbit:
F(1-912 A) = 2.0726e4 (log 4.3165, against Salz's stated log F_XUV = 4.32),
F(10-912 A) = 2.0430e4, F(912-2600 A) = 1.8409e5 erg cm^-2 s^-1;
F(10-912 A) is the band a run actually integrates.

**Normalization and distance, READ from the file header.** eps Eri (K2V,
MUSCLES v22 const-res) at Earth, scaled by `(d/a)^2 = 4.567494e14` with
`d = 3.212 pc` and `a = 0.0310 AU` (Salz Table 2), no radius correction; then
Salz's four regions: `lambda < 100 A` to `log L_X = 28.18`, the Ly-alpha
window 1206-1226 A above its local continuum to `log L_Lya = 28.43`,
100-911.6 A to `log L_EUV = 28.61` (Salz Table 3), and no renormalization
longward of 911.6 A. The orbital distance of the file and of this input agree
at 0.031 AU, which is the value this file was corrected to.

**Active absorbers and the grid floor.** He 2^3S on (`Include He23S? True`);
H(n=2) armed by `Stellar Teff [K]: 4875` and `Stellar radius [R_sun]: 0.765`;
no `metals.inp`, so metals off. The lowest threshold is the H(n=2) Balmer edge
at 3.3996 eV = 3647.0 A, so the photon grid runs 3.3996 to 1240 eV. The file
reaches 4999.9 A.

**Dayside dilution.** `2D approximate method: Rate/2 + Mdot/2`, so every
stellar beam is multiplied by 0.500.

**Coverage check.** `sed_coverage_and_order_check.py` carries the file rules
and the band fluxes of this file (exit 0, MEASURED 2026-09-06) but has NO
configuration entry for `benchmarks/hd189`; its per-configuration coverage
table lists `HD189733b`, which states the same floor (H(n=2), 3647.0 A) and
names the same file. The metals of the planet folder do not change the floor,
since none of them has a threshold below the Balmer edge:

```
  # HD189733b: He23S=True Teff=4875 R=0.765 metals=C,N,O,Mg,Ca,Na,Fe
  #   required band 10.00-3647.0 A (3.3996-1240 eV); long endpoint set by H(n=2), the Balmer continuum: Stellar Teff and Stellar radius are both set; short endpoint by E_high with X-rays on

PASS HD189733b:named:hd189733b_epseri_salz2016.txt:reaches_short_endpoint measured=3.9392 A reference=<=9.9987 A tol=exact
PASS HD189733b:named:hd189733b_epseri_salz2016.txt:rows_in_window measured=3637 reference=>=2 in [9.9987,3647.0] A tol=exact
```

**Consumer check on the binary.** A two-step run (`EXHALE_MAXSTEPS=2`) of a
scratch copy of this directory, MEASURED 2026-09-06, setup report:

```
 - Log EUV luminosity: 28.611 [erg/s]
 - Log X-ray luminosity: 28.160 [erg/s]
 - Log XUV flux at the planet distance: 4.311 [erg/(cm^2 s)]
 - Including helium triplet chemistry
 - Coupled equilibrium system size: N_eq = 4
  - Spectrum read from external file: ../../inputdata/sed/hd189733b_epseri_salz2016.txt
 - Spectrum type: Load, and it builds every band of the photon grid
   Below 13.6 eV (down to   3.40 eV): the same SED file as every other band.
   Integrated grid flux sum(F dE) =  6.5658E+06 erg cm^-2 s^-1 (after the dilution)
     against the nominal (10^LX + 10^LEUV)/(4 pi a^2) =  1.0230E+04 at the same dilution: ratio  641.793
 - Dayside dilution applied to every stellar beam:  0.500
```

`read_sed` accepts the file at this configuration's 3.40 eV floor, and the
recomputed `LX`/`LEUV`, 28.160 and 28.611, reproduce Salz's Table 3 values
28.18 and 28.61 to 0.02 and 0.00 dex. `log F_XUV` at the orbit goes from 4.438
(the power law, from the `LX = 28.420`, `LEUV = 28.680` this file used to
carry) to 4.311, a factor 0.746.

**Reruns are a separate instruction.** Nothing here was re-run, re-converged
or deleted, and neither the LaRT cases built from `output/` nor the `insitu_*`
products were touched. Producing a wind under this input is a D-physical step
of `docs/PLAN_20260906_rev2.md` section 3, gated on its own prerequisites and
on an explicit instruction.
