## 3. Execution order (rev 2)

Roles as before: the advisor writes contracts and briefs and verifies diffs
and tests; workers implement; the user decides where a row says so. Every
code step carries its test (RED before, GREEN after) and a scoped impact
measurement on the paths it touches; goldens are refreshed once at the end of
a series and reported. No tolerance is chosen to preserve a snapshot or a
convergence label.

### Step A. Acceptance contracts and run modes

**A0. Run-mode contract** (advisor writes, user accepts). Three states:
initialization/continuation (non-root iterates allowed as numerical guesses;
no physical time, reaction budgets, heating budgets or observational
histories accumulate; `Time stepping: Local` and the PTC route belong here),
physical integration (one global step per accepted update; every accepted
step satisfies its time-discrete balances, admissibility, invariants and
integration-error requirement; a valid finite-time state is writable without
a zero stationary residual), certified stationary solution (A2 stationary
certification on the exact written state). Handoff: an admissible,
source-consistent state, dependent caches rebuilt from it, the physical time
origin declared, or a stated failure. Diagnostic snapshots (the fixed-step
`mol_*` cases) are relaxation states, never certified transients. Class 4
exists only in initialization mode.

**A0-impl. Run-mode implementation** (one worker, after the contract and
after the user confirms the input/API form). Mode bound to the time-step
strategy: a physical-mode run with local pseudo-time stepping is refused or
kept explicitly in relaxation mode with no physical-time claim (a closed
two-cell update with unequal steps does not conserve the material sum, so
local stepping is not a physical step). Counters separated: iterations,
attempted steps, accepted physical elapsed time (advanced only after a
complete accepted physical step, never the minimum pseudo-step).
Initialization records kept but never counted as physical histories. Restart
metadata: mode and time origin in the headers, so a relaxation snapshot
cannot become a physical history with an invented clock. Tests: incompatible
mode/stepping combinations; handoff failure; rejected-step time accounting;
reload of an initialization snapshot versus a physical one. The physical
temporal-refinement tests of A3 and B3 run in physical mode only.

**A1. Status and classification contracts** (two workers, disjoint files).
- Carrier solve: acceptance on the RETURNED state, every unconstrained row,
  absolute or physically scaled floors, regardless of the termination branch
  (`converged`, `accepted_at_floor`, limiter applied afterwards); the
  relative-drop branch (`rnorm <= 1e-6 rstart`) becomes a diagnostic;
  constraint activity recorded by cell, never certifying a failed row.
  Tests: successful raw status then an active limiter; failed raw status
  with a constrained worst cell and an unacceptable unconstrained row; large
  relative drop with an unacceptable final residual; non-finite rows; an
  otherwise valid constrained state.
- Acceptance classes: one meaning for every consumer; a class-5 root has the
  validity of a class-1 root; a class-4 state passes no final acceptance.
  Tests: equivalent roots through classes 1 and 5 get one verdict; a genuine
  class-4 state is refused.
- Gate: scoped impact measurement; identity expected only where the changed
  branch is shown unused; changes recorded and explained.

**A2. Common evaluator, context-specific acceptance** (advisor design on
B1a's inventory, one worker).
- One evaluation of the active-equation inventory on a given state and
  field: each independent transported carrier balance (H2, H+, and OH/H2O/CO
  when the oxygen network is on), the active elemental transport balances,
  the algebraic closures only for species eliminated by a justified fast
  process, mass, charge and energy conditions, boundary equations by cell
  class, the validity state (B6). The steady equation of a transported
  species is transport minus reaction. Evaluation status per equation (not
  applicable / evaluated / unavailable or invalid); finite values required;
  an active but unevaluated equation cannot pass. Side-effect-free, or an
  isolated workspace; never re-equilibrates a transported partition to
  measure it; uses the backgrounds of the state being certified.
- Four decisions from that evaluation, with different conditions:

| Context | Required | Not required |
|---|---|---|
| Residual/Jacobian probe | usable residual of the requested equations, domain checks, controlled inner-closure error, no adoption or persistent mutation | global stationary convergence |
| Stationary Newton trial | physical bounds, valid inner closures (a class-4 chemistry is not a valid closure), then the merit-decrease or trust-region rule | zero global residual on every trial |
| Completed physical time step | the time-discrete balances, admissibility, invariants, the integration-error requirement | a zero stationary residual |
| Certified stationary output | every active stationary equation, constraint, validity condition, exact output-state consistency | nothing may be skipped |

- The marching caller's `.false., 0.0d0` carrier condition and the
  uncertified-cell count in trial handling are replaced by these decisions:
  valid local closures in trial handling, stationary tolerances only at
  certification.
- Norms: one condition per active independent balance with units, floors
  and a local safeguard at fronts; the combined `rvol` reported, not
  decisive.
- Tests: active carriers with `bg_ready` false (unavailable, never a pass);
  inactive model (not applicable); stale background after a state change;
  repeated evaluation around output calls preserves the state; small-rate
  species beside a balanced dominant one is caught; oxygen carriers, H+
  transport and active element diffusion all evaluated; a positive,
  merit-decreasing Newton trial with a large global residual is admissible
  as an iterate but not certifiable; a valid transient with a nonzero
  stationary balance passes as a step without a stationarity claim; a trial
  with invalid eliminated-species chemistry is not treated as a valid root.

**A3. Carrier-only rejection and retry** (active carrier transport only;
after A1, A2 and the carrier-local checkpoint). Checkpoint first: carrier
fractions, saved backgrounds, photolysis arrays, advection corrections, row
scales, headroom, constraint diagnostics, the cumulative CO record;
restore tested. Then the controller: on a failed returned-state acceptance,
restore, halve the carrier substep with the background explicitly frozen
(which coefficients stay frozen and which follow the carrier state is
stated), cover the interval with accepted substeps, bounded retries, dt
floor, then stop with the reason; the entry state or a clearly marked
partial diagnostic state survives a permanent failure, never a report of
completion. Rejected trials never enter the accepted CO record or step
statistics. Labeled partial recovery. Tests: injected failure after an
accepted substep and after counter/cache mutation; complete restoration;
correct elapsed interval; agreement with an explicitly subdivided
integration; temporal refinement at fixed end time in physical mode.

### Step B. Target governing system and its implementation

**B1a. Active-equation inventory and validity-state interface** (advisor,
short, before A2): per configuration flag, the independent equations, the
eliminated species and their closures, the boundary equations by cell
class, and the validity states of B6 with their semantics (active
unvalidated physics; out-of-domain closure; rejected trial with no adopted
contribution, which does not invalidate; unbudgeted accepted correction,
which invalidates; specified external reservoir, informational). This list
also generates the D-physical prerequisites of each configuration.

**B1. Target specification** (advisor writes, user accepts; the Phase 2
gate). Separate from the D0 audit; for every C-item a target equation, an
owner, an acceptance test. Contents as in rev 1 (thermal plus kinetic energy
with an explicit formation/excitation ledger and a conservative coupled
temperature-composition solve; the temperature-preserving pressure reset
removed as an independent update; chemistry preserves the supplied density;
independent species space and constraints, constrained Jacobian on it;
derived ambipolar closure with a stated current condition; CO model or
exclusion with the cumulative record as observable; H2 internal-energy
convention shared by EOS and chemistry; H3+ emission model from the
published fit definitions with its domain; oxygen energy ledger or
exclusion; `_adv` on the same assembly or refused; Lyman-alpha excitation
loss and de-excitation return derived together under local ownership;
boundary constraint count; the rollback contract as the enumerated
checkpoint of the whole attempted step including viscosity/conduction and
the Shapiro filter when active; the verification matrix).

**B2. Residual-controlled temperature solve.** Bracketed or safeguarded
iteration, sources at the returned temperature, final residual test; an
unacceptable update returns a failure status and stops safely (no recovery
claimed before B3a). A floor is either a physically specified reservoir with
its heating budgeted or a failure. Required wherever the semi-implicit
thermal path is used, the pure H/He case included. Tests: falling cooling
branch, strongly temperature-dependent heating, unavailable bracket, floor
encounter.

**B3a. Attempted-step controller** over every state-changing operation up
to the adoption boundary (hydro, diffusion, carriers, radiation and
chemistry, energy, viscosity/conduction, Shapiro filter when active) with
B1's checkpoint: save, trial, evaluate (positivity, element and charge
constraints, time-discrete residuals, energy budget), adopt or restore and
shorten, stop with diagnostics after the retry limit; accepted statistics
exclude rejected trials. It may be built and its restoration tested against
the existing update before B3c; that demonstration does not certify the old
composition reset, and no energy tolerance is loosened for it. Tests:
mutated trial fully restored; elapsed time correct; no rejected contribution
in any accumulated record.

**B3b. Rates, energies and thermodynamics the source step needs** (rev 3
Phase 3 increments, each with its own test, applied where the process is
active): photoevent energy partition including the H2 channels and excited
recipients; reaction heats including oxygen and associative channels or
their exclusion; the common H2 state model and consistent thermodynamic
functions; the H3+ absolute emission model with joins and domain;
finite-rate evolution of species not legitimately eliminated (an explicit
increment). Independent tests against analytic limits, conservation
identities and published data within their ranges.

**B3c. Coupled species-energy source step and the final-state assembly
contract.** One solve for temperature and composition under the energy
constraint; the pressure reset removed; chemistry mass-preserving. One
consistent instantaneous evaluation feeds certification, the endpoint checks
and every output file; a substepped or multistage update keeps its
time-integrated source budget at its own time levels; both use one
definition per process. The diagnostic recomputation of
`write_heat_breakdown_eq` and the `excited_H_update` before the final write
are replaced by that assembly or shown not to mutate the certified state.
`output_state_consistency` turns GREEN as one check among several. Temporal
refinement and splitting-order tests at fixed end time in physical mode.
Goldens refreshed once at the end of this series.

**B4. Conservative spatial operator** (rev 3 Phase 4): species face fluxes
consistent with the mass flux, thermal and chemical energy transport with
the same face fluxes, the charged closure and background response for
diffusive mass conservation, the hydrostatic residual and boundary
constraint count for the active system. Tests: diffusion-only column;
reacting transport balance; mass, elements, the stated current condition and
material energy closing with consistent face fluxes.

**B5. Stationary equations on the same terms** (rev 3 Phase 5): species
rows for every active transported balance on B1's independent space, the
same source assembly as B3c, the same face fluxes as B4, A2 certification as
acceptance, Jacobian-action checks, inner-solve determinism, reload and
acceptance consistency. `Ionization transport` with `Solver: Newton`
becomes supported by derivation or stays refused with the reason. Optional
for any configuration whose time-converged solution passes A2
certification. Its completion depends on B3c, B4 and the current A2; its
interfaces may be built earlier.

**B6. Validity state** (rev 3 section 4.2 last item): semantics defined in
B1a, the reporting and certification interface delivered with A2, the
producers delivered with their processes (the CO destruction domain with the
carrier step, the CO ceiling that stood there having been deleted on
2026-09-06, item CEILING-DEL; oxygen ledger with B3b, floors with B2, closures
with B4); printed with
every final state and carried into the output headers. Not dependent on B5.

### Step C. Spectra and configurations (data preparation independent of A and B; consumer tests re-run after B3b, B3c, B4 or any change to cross sections, photoevent energies or active absorbers)

**C1. Loaded-field semantics and consumer validation.** State whether table
values are point samples or bin averages and reconstruct accordingly; test a
narrow line, a sharp threshold, a coarse bin and a steep continuum through
the production photoionization, heating and Balmer consumers; require rate
convergence with resolution; compare band energy and photon number of the
grid against the source table; include the 10 A upper cutoff in every
integrated XUV comparison. Configuration-specific coverage tests from the
active threshold inventory (2600 A metastable; 3647 A when both `Stellar
Teff` and `Stellar radius` arm H(n=2); the lowest active metal), replacing
the script's single K I floor check; labels match the bands computed. The
hot-Uranus stand-in table (to 2995 A) does not cover the full required Balmer
continuum; the production guard stops such a run.

**C2. WASP-121 b candidate C.** Solar XUV below 1700 A at the chosen 1.6e6
normalization, the scaled WASP-17 photosphere above, neither component
renormalized to force continuity, join ratio reported; header: provisional
composite, proxy photosphere, XUV normalization as chosen. A/B/C He 2^3S
rates through the production integrand on one prescribed state and
attenuation, reported as sensitivity. Prerequisite for the WASP-121 b switch
only.

**C3. Configuration switches**, one at a time, each after its own C1
checks: purpose, reference model, SED file and checksum, coverage, units at
the orbit, distance and normalization assumptions, active absorbers and
dilution in the folder README; previous outputs kept and labeled with their
input. HD 189733 b: the Salz-normalized file for the Salz comparison; the
Bourrier file (visit stated, or the B-E mean with variability as an input
uncertainty) for the observed-star model. HD 209458 b: the WHI 2008 file.
WASP-121 b: C after C2. `VULCAN/atm/stellar_flux/sflux-HD189_B2020.txt`
untouched.

### Step D. Validation (instruction-gated, by purpose)

**D-diagnostic.** Bounded development runs, explicitly requested, at any
time; limitations in the header; never presented as validated predictions.

**D-physical.** Prerequisites generated per configuration from B1a's
inventory by active code path:
- always: A0 and A0-impl (physical mode), A1, A2, the exact output state
  (B3c's assembly), B6 state clear or the run excluded, C1 and C3 for its
  input field;
- reactive composition or thermal source update active (every present
  configuration, pure H/He included): B2 and B3c (the reset removal); B3a
  wherever recoverable rejection is claimed;
- carrier transport active: A3; molecular, oxygen or metal processes
  active: the corresponding B3b items (inactive ones recorded as not
  applicable; pure H/He does not wait for H3+ or oxygen work);
- species or element transport active: B4;
- direct Newton (B5) not required where a time-converged solution passes A2
  certification.
A pure H/He reactive case is not eligible while the temperature-preserving
composition reset is part of its source update.

**D-comparison.** A published reproduction additionally requires matched
boundary conditions, geometry, composition, rates and spectral assumptions,
or an explicit list of the unmatched terms.

**D-figures.** Paper and poster figures last, only on explicit instruction.
