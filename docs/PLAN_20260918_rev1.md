## D1. The default base cell width and the input key

### Facts, READ

`parameters.f90` line 143 and `input_read.f90` line 451 assign
`dr_base = 2.0e-4`, a default-real literal, stored as
`1.9999999494757503e-4`; the key is read list-directed into a `real*8`, so
`2.0e-4` in the key gives the exact double, 2.53e-8 relative above the
default (review arithmetic check). The comment above the literal states
the choice as deliberate (bitwise reproduction of runs made before the key
existed) and states the trap (the spelled-out default does not reproduce
it). L35 MEASURED cell centers differing by up to 6.58e-9 relative on the
catalog grid between the two; `load_IC.f90` lines 2221 to 2244 refuse a
restart whose centers differ by more than 1e-10. `dr_base` enters the
`Mixed` branch of `define_grid` only (lines 31 to 34).

### The defect

Two inputs any reader would call identical build two grids whose states
refuse to load into each other. The refusal itself is right: loading a
state onto a grid it was not written on is interpolation, and the 1e-10
check must stay. The defect is the contract, not the physics (2.5e-8 in one
cell width).

### Corrections to the first text

- "Every grid moves": only Mixed grids built from the default move. Grids
  whose width is stated in the key, and other grid types, do not.
- An archived state does not have to be MAPPED because the default
  changes: it keeps its grid by stating its resolved width and base-cell
  count explicitly. Mapping is for moving a state to a different grid on
  purpose, and a mapped state is a seed, not a certified solution of the
  new operator.
- The forecast "movement at the level L30b measured for a 4e-13 seed" is
  withdrawn: a grid change is not a rounding perturbation and L30b's
  numbers do not predict its response.
- 17 digits are not printed today: `put_r` uses `ES23.15E3` (16
  significant digits). The disclosure goes into `write_resolved_config`
  (machine-readable) with a round-trip format (`ES24.17E3` or the shortest
  exact decimal), not into the human report alone.
- "Default or key" needs a provenance flag set by the reader; value
  equality cannot say where a value came from. The duplicated literal in
  `input_read.f90` is replaced by one named default in `parameters.f90`.

### Steps

D1a (now, no numerical change): one named default `dr_base_default`; a
logical `dr_base_from_key` set by the reader; `write_resolved_config`
records grid type, width (round-trip precision), base-cell count, cell
count, outer radius and the provenance flag; `docs/input_schema.md` states
the stored default and the trap; `write_reproduce.py` writes the key from
the resolved record. Tests: the grid built with the key absent and with the
key stating the resolved value are identical to the bit (coordinates
compared directly); the key stating `2.0e-4` differs, and the row reports
the measured maximum for the grid under test as an observation (not a
hardcoded 6.58e-9, which is the catalog grid's number).

D1b (on the user's approval, for NEW configurations only): the default
becomes `2.0d-4`; every archived reproduction input states its resolved
old width and count explicitly (from the D1a record; where the provenance
is not established the reproduction file says so instead of assuming the
present default); no archive is mapped for this reason; regression: the
matrix at strict tolerance on the control and measured builds, the
movement reported case by case, goldens refreshed once with the previous
set kept. A catalog re-solve is not a prerequisite.

### Separate from D1: the base face geometry under refinement

L35 also found that the Mixed construction ties the inner physical face to
the first cell width (`r_edg(0) = (1 + r(1))/2`), so refining the width
moves the numerical boundary relative to the reservoir level. That is a
grid-design question with its own item; neither D1a nor D1b addresses it,
and a resolution study must state whether it held the physical face fixed
(L35 did, by solving for the two keys).

## D2. The base boundary at zero and reversed flow

### Facts, READ

L26 wrote the window's say as `s_wind = A(M_wind) C(d_window)`;
`characteristic_branch_weight(x)` is the cubic `0.5 - 0.75 x + 0.25 x^3`
(`base_boundary.f90` lines 489 to 505), 1/2 at zero. L35 MEASURED on the
fiducial with momentum and kinetic energy removed: window flux zero,
face Mach zero, `w_rev = 1/2`, base density the average of the reservoir
and interior isentropes, 3.79 per cent below the reservoir; the production
closure's base mass flux on that fixture 1.2751e-5, the local candidate's
1.3791e-5 (L35 memo line 679).

### What the first text got wrong

It argued that at rest no characteristic leaves the domain, so the face
must be the reservoir. At rest the characteristic speeds are `-c_s, 0,
+c_s`: one acoustic characteristic leaves, one enters, and the contact is
stationary. The code's own outgoing relation (`C-`, line 37) gives
`v_b = v_i + (p_b - p_i)/(rho_i c_i)`, so zero interior velocity does not
make the face velocity zero; a pressure mismatch launches a legitimate
acoustic response, which is what the fixture's nonzero base flux is. And
the fixture is not a hydrostatic equilibrium: it is a wind with its
momentum deleted. So the measurement shows that the blend's value at zero
is a model choice with no stated physics behind it; it does not show that
the reservoir density is the right value, and the "+8.2 per cent" of the
local candidate is not a restoration of equilibrium.

Also withdrawn: "a C1 factor that is 0 at exactly zero flow and 1 wherever
either discriminant is resolved, leaving every flowing state byte-identical".
A continuous weight equal to the old one at every nonzero argument is 1/2
at zero; a weight that vanishes at zero changes a neighborhood of zero,
whose width is a parameter that must be justified (review arithmetic
check: the difference quotient of a change confined to zero diverges).
Byte identity can be measured on chosen saturated states; it cannot be
promised for all flowing states.

### The item

D2a, a decision the user makes on a stated model, not on a formula:
- which thermodynamic quantities the lower atmosphere prescribes and at
  which reference radius (`base.inp`: `p_base`, `T_base`, `q_H2_base`, the
  element reservoirs; the match level);
- whether entropy and composition are imposed only on inflowing material
  (the entering characteristic and the contact when it moves inward) or
  also through a thermal/contact model when the contact is at rest;
- how a stationary pressure-balanced contact with different interior and
  reservoir entropies is treated;
- how the boundary passes through weak inflow, weak outflow and reversal
  without imposing outgoing information.

D2b, after that: implement the stated model in `base_boundary.f90` with
the blend width, if one remains, named and justified; tests on a
manufactured DISCRETE hydrostatic state consistent with the molecular
equation of state and the reservoir (face velocity, mass flux, momentum
and energy balance), a stationary pressure-balanced contact with differing
entropy and composition with its expected behavior stated in advance,
acoustic perturbations of a static background (the outgoing acoustic
information retained), weak flows of both signs with directional
derivatives around zero local and zero window flux (including a zero
window mean with nonzero spatial fluctuation), and the reservoir-limited
and interior-limited branches compared in composition, pressure, caloric
energy and characteristic count together. Regression movement reported,
not promised away.

D2 stays separate from D5: D5 makes the declared boundary reproducible;
it does not select a different entropy model to pass a restart test.

## D3. The transported He II row

### Facts, READ

L36d: on `carrier_model_a_newton` with `Ionization transport: True` the
`carrier balance He+` row stands at 9.99e-1 to 7.74e-1 over 25 passes at
cell 248 while H+ and He++ stand at 2.3e-4 and 1.8e-4; on the control's
locally equilibrated composition the same row reads 4.151e-2, the two
builds' He II agreeing to 0.20 per cent. The certification denominator
(section 0) is `row_terms_phys`: face diffusive terms over the volume,
absolute advective terms, the absolute NET chemical source and the
absent-carrier term. The helium diagnostics `sprod`/`sloss` are the parts
of the net source, not gross channels. The stage-sum entry is report-only.
The manufactured-column test's normalized order 2.886 is measured against
a scale that grows as `1/h`.

### What the first text got wrong

"No composition can certify" is not demonstrated. At a discrete steady
root `R = D - (P - L) = 0` whatever positive scale divides it. A locally
equilibrated control satisfies `P = L`, not `D = P - L`, so it is not an
exact reference for the transported problem where `D` is nonzero; a small
abundance difference (0.20 per cent) can coexist with a large residual in
a stiff reaction. A denominator containing `|P - L|` is badly conditioned
near local equilibrium when the transport is small, which is a real
concern, but it is a conditioning statement, not a proof. The first
text's two candidate scales were both misreadings of the source, and its
step 3 (choose the candidate under which a correct state certifies and the
RED-by-construction rows fail) would select a denominator by the fixture's
outcome, which the sharpened standing rule forbids.

### The item

D3a, measurement, on the L36d fixture's solved state and on the control's
state, at the worst cells and over the column, with the transported
fractions held according to their ownership:
1. A channel-rate diagnostic exposed from the production chemistry
   (`mol_heh_rows` and its source corrections, `System_HeH_mol.f90`):
   gross production and gross loss of each stage by channel
   (photoionization, secondary and collisional ionization, charge
   exchange, the He 2^3S channels, recombination, ionization to He III),
   as optional output of the same expressions the residual uses, never a
   second spelling in a test. `sprod`/`sloss` are relabeled for what they
   are (parts of the net source).
2. At the worst cells: `P`, `L`, `P - L`, advection, diffusion, the
   unscaled residual, every component of `row_terms_phys`; the reaction
   sensitivity to the stage fractions and to `n_e`; the abundance
   correction that would balance the transport, about `D/(d(P-L)/dx)`;
   the cancellation floor of `P - L` (a higher-precision evaluation of the
   source where practical); the smoothness of the residual under
   budget-respecting perturbations; whether the sweep and the transported
   source evaluation use the same composition and radiation field.
3. Manufactured cases that the present column test lacks: a stiff
   ionization-recombination cancellation with independently large `P`
   and `L`, several chemical-to-transport timescale ratios, the Mixed
   grid, and the actual boundary operator; the dimensional residual
   convergence and, where available, the solution error reported beside
   the acceptance-normalized one, with a grid-independent reference scale.
   The recorded normalized order 2.886 is re-stated as what it is
   (normalized by a `1/h` scale).
4. The stage-sum entry gets a floating-point bound consistent with the
   number and size of the summed terms (an algebraic identity has no
   truncation error), validated by execution, and becomes gating; it does
   not wait for a spatial tolerance.

D3b, decision (user), on the D3a memo: keep the gate, add complementary
criteria where stiffness requires them (chemical backward error, transport
and global inventory balance, and the abundance or observable error the
remaining residual implies), or find a solver defect the measurement
exposed. When norms are compared, the DIMENSIONAL residual each admits
(`tolerance x scale`) is compared, not the normalized numbers. If a fast
stage is to be eliminated by local equilibrium, its timescale validity is
stated and the reduced model validated; a "certified" label with a
required balance omitted is not an option. Solver work is not excluded in
advance.

D3a depends on D6: the balance of a helium stage is measured on states
whose helium inventory is admissible.

## D4. The thermochemical closure's returned state

### Facts, READ

`carrier_retry.f90` lines 1263 to 1300: one further sweep on the
composition production returned; movement of every species above 1e-20
compared with `ieq_res_tol = 1e-6`. On the L36c text 1.034627e-6 (RED),
entry text 2.685237e-7; binding species HeH+ at 1.33e-12 of the gas in
cell 1. L36d: a THIRD sweep moves it by 1.0085e-10; the chain
H2+ -> H3+ -> HeH+ amplifies the parents' movement by an order of
magnitude a step; H3+ carries 53 per cent of the cell's electrons.
`equilibrate_chemistry_at_fixed_conserved_state` (`diffusive_photochemistry.f90`
lines 7014 to 7124) ends on `dT/T < chem_cycle_tol` alone (line 7107),
with its nonfinite and inadmissible-state refusals and its cycle budget.

### What the first text got wrong

Its option (1) had the TEST iterate the sweep until the movement fell below
the tolerance. That replaces the assertion about `T(x_returned) - x_returned`
by one about `T(x_k) - x_k` after the test advanced the state: a different
contract under the old name, and a test cannot improve the state the
production caller received. The 1e-10 third-sweep number is diagnostic
evidence, not a pass. Its option (2) (a physical presence rule) was also
premature: `f_sp > 1e-20` is a numerical presence rule, and a low-mass
species can dominate the electrons or a pathway (H3+ here), so HeH+ is not
dismissed for being small. And "the movement must decrease monotonically
over the sweeps" is not a property of a convergent coupled iteration
(review check: spectral radius `sqrt(0.1)` with successive changes 1, 10,
0.1, 1).

### The real question

Production's closure promises a closed thermochemical state and ends when
the temperature stops moving. The comment's claim that a temperature
change below the reaction tolerance cannot move the composition beyond it
has no general basis: a trace abundance can move with no caloric effect,
a temperature-sensitive rate can amplify a small thermal change, and the
rates and sources kept from a sweep at the previous temperature must be
bounded against the returned one. Separately, `ieq_res_tol` is a reaction
RESIDUAL tolerance and does not bound the relative abundance movement of
every species after another nonlinear sweep without conditioning
information. So two outcomes remain open: production exits early against
its own promise (repair the stopping rule), or the test assumes a stronger
bound than the residual contract gives (revise and rename the assertion
with a defensible norm and add a direct returned-state residual check).
Neither is settled by iterating the test.

### The item

D4a, measurement on the fixture:
1. Save the unmodified production return and everything needed to
   evaluate it consistently (composition, temperature, `n_e`, the
   transported fractions with their ownership, the radiation field).
2. Its chemical residuals at the returned temperature and electron
   density, species by species, against `ieq_res_tol`; the binding cell
   and species.
3. One complete fixed-conserved-energy closure increment (chemistry AND
   the equation-of-state temperature update), not repeated chemistry at
   frozen temperature; the size of the thermal and the chemical parts.
4. Whether failed trials restore composition, rates, caloric state and the
   boundary context the next trial reads.
5. The conditioning that relates `ieq_res_tol` to an abundance movement
   for the binding species.

D4b, on D4a's memo: either the closure's success condition gains a
chemical residual (or increment) criterion at the returned temperature
with the binding cell and species reported and an explicit failure when
the cycle budget is exhausted, or the test's abundance-movement assertion
is revised and renamed with the norm D4a justifies and a direct
returned-state residual assertion added. In both cases extra settling
sweeps stay a SEPARATELY named diagnostic and never overwrite the
returned-state assertion. `ieq_res_tol`, `chem_cycle_tol` and the 1e-20
rule are not moved to make the row pass.

5. Same-state operator agreement between the in-run certification and the

6. Repeated evaluations and a fresh process: no physical cell drifts

## D6. Helium held in HeH+ is not reserved from the helium ion-stage simplex

### Facts, READ (section 0)

`carrier_state` takes total helium nuclei from `element_nucleus_counts`,
which counts HeH+ by stoichiometry; `carrier_nucleus_reference` normalizes
x(He II) and x(He III) by that total; the projection imposes
`x_HeII + x_HeIII <= 1` alone; `carrier_source` forms neutral helium as
`max(N_He - n_HeII - n_HeIII - n_HeH+, 0)`; the write-back forms the
remainder the same way and rescales the held neutral helium onto it.
Counterexample (review, executed arithmetic): HeH+ 0.10, x(He II) 0.60,
x(He III) 0.35 passes the simplex (0.95) and leaves an inventory of 1.05
after the clip. Reachability in a production run was NOT tested; the
defect is in the expressions.

### Why it is fixed regardless of reachability

Conservation of helium nuclei is an invariant the operator claims, and a
projection that admits a state violating it is wrong whether or not a
catalog run has reached one. It also gates D3: a helium balance measured on
an inadmissible inventory is not a measurement of the row.

### The item

Constraint: `x_HeII + x_HeIII <= 1 - n_HeH+/n_He,nuc` (and any further
helium-bearing molecule by stoichiometry), applied identically in trial
admissibility, finite-difference perturbations, source evaluation,
projection and write-back; no clipping of a negative neutral remainder
while the positive species stand. If the normalization is changed to an
atomic-helium pool instead, the flux and source definitions change with
it; the limiter alone is never changed. Tests measure the actual returned
species: total H nuclei, total He nuclei, total mass and charge, with
nonzero HeH+, nearly exhausted neutral helium, physical cells and ghosts
by their ownership; the algebraic stage-sum row is not this test. RED on
the entry text with the counterexample state; GREEN after. Key-off byte
identity on the four cases of L36e; key-on movement of the `hp_*` and
`carrier_model_a_newton` states reported.

## D7. Metal charge exchange is absent from the ionization stage sources (L36e finding)

## D8. The catalog runner's continuation and the state pair of a stopped run

### Facts, READ from the L34c report (MEASURED there)

- `run_case.sh` continues a solve in pseudo-time whenever the first solve
  does not return `info = 0`, including when only the composition refuses
  (the L4e rule). On `molecular_scalar_gj1132_wellmixed/HeH0.083` the first
  forty passes reached 4.13e-2 on the gated carrier row and the
  continuation's forty took it back to 7.37e-2; the state on disk is the
  continuation's. The composition movement bound only ever halves within a
  run (`EXHALE_main.f90` lines 7086 to 7087): 1.0e-2 to 5.0e-3 at pass 14,
  held for 27 passes; the continuation starts at 1.0e-2 again and the row
  rises there.
- A solve writes `Hydro_ioniz.txt` only when it ends, so a run stopped
  inside one leaves the previous run's state beside its own `*_IC.txt`
  seed: `kzz1e9/HeH0.55` and `wellmixed/HeH0.55` now hold such pairs, and a
  stale `run_dtau0_first.log` outlives its run on both.
- L33 had already found the bound throttling the K_zz case (2.49 to 1.04
  per cent a pass as the bound halved) and named restoring it on a pass
  that makes progress as a third option beside "more passes" and "no
  bound".

### The defect

A run directory must state one solve: its seed, its trajectory, its best
state and its ending. Today it can carry the continuation's worse state
over the first solve's better one with no record, and a stopped run can
carry two halves of two states under one name. Both are contract defects
of the runner and the writer, not of the physics, and both mislead the
catalog tables and every seed taken from those directories.

### The item

1. The runner keeps the best certified-or-nearest state of every solve it
   launches (`output_best/` with the pass and the gated rows that made it
   best) and never overwrites a better state with a worse one; the
   continuation is taken only when the first solve's ending is one the
   continuation addresses (a hydrodynamic refusal), not when the
   composition alone refuses; the rule is stated in `run_case.sh` where it
   fires.
2. The solver writes the state pair atomically at every accepted outer
   pass (both files, or a checkpoint pair with the pass number), so a
   stopped run leaves one consistent pair and its log says which pass it
   is; `write_output.f90`/the outer loop own this.
3. The movement bound's recovery on a progressing pass is a solver-control
   change (the closed stage-2 program): it is NOT made here; its
   measurement (hold the bound at 1e-2 for ten passes on the stopped
   `wellmixed/HeH0.083` state, as L33 designed) is the bounded experiment
   the user may open, and its result decides whether an item exists.
4. Tests: a runner fixture whose first solve refuses on the composition
   only must not continue and must keep its state; a run stopped by signal
   at pass k leaves a pair whose two files carry the same pass stamp.

## D9. The pass budget of a transported-ionization solve, and the key-on goldens

### Facts, READ from the L36e report (MEASURED there)

On the certified atomic fiducial with `Ionization transport: True` the
worst gated species row fell only 3.51e-2 to 1.76e-2 over passes 1 to 25
while the binding cell marched outward 217 to 491, about 3.3 cells a pass:
the restart's local-equilibrium partition is replaced by the transported
one and the front has to cross the column; it reached the outer boundary
at pass 26 and the measure then fell monotonically to 8.68e-6 at pass 56,
where the state was ACCEPTED and CERTIFIED. The four key-on regression
goldens are stale (`hp_front` 1.6e-1 in the helium columns, `hp_zero_seed`
3.9e-3, `hp_trace_seed` 3.3e-3, `carrier_model_a_newton` 1.2e-4 through
the He <-> H charge exchange the stage sources now carry).

### The item

1. A campaign judging a transported-ionization configuration uses a pass
   budget that lets the front cross the column (for a 500-cell domain at
   3.3 cells a pass, at least 40 passes before any gated row can begin to
   fall; 56 certified the fiducial); `run_campaign.sh` states the budget
   by configuration, and a run stopped by the budget records the binding
   cell's position so a front is not read as a refusal.
2. The four key-on goldens are refreshed ONCE with the L30 refresh of this
   series, the movement stated as the transported stages (a physics change
   the key selects), not as a defect.
3. A seed for a transported run is better taken from a transported
   certified state of the nearest configuration than from a
   local-equilibrium one; `pick_seed.py` learns the key as a tier
   discriminator.

## What this plan does not do

It does not weaken `c_round`, `ieq_res_tol`, `chem_cycle_tol`, the 1e-20
presence rule or any certification gate; it does not choose an acceptance
denominator by a fixture's outcome; it does not let a test advance the
state it judges; it does not move the default grid width for existing
configurations; it does not select a boundary blend before the boundary
model is stated; it does not evaluate or rewrite catalog products in place;
it does not promise bit identity or the certification of historical states
in advance. Reference outputs move only where a conservation or boundary
correction moves them, once per change series, with the movement reported
(D1b, D6, D5b, D2b each say so in their steps); the first text's closing
sentence that none of the items refreshes a reference was wrong and is
withdrawn.

Two small follow-ups of the `count` rename are recorded and not scheduled:
the printed labels `count=` (the marching log) and the report key
`count_max` (`EXHALE_setup.out`) keep their old words because
`src/tests/attempted_step/run.sh` and the archived logs read them; bringing
label and variable into line is one change with that reader and a log
snapshot. Three loops that existed only because the intrinsic was shadowed
(`csm_n_moving` in `EXHALE_main.f90`, `l15_number_of_active_bounds` in
`steady_newton.f90`, the `NlTR` loop in `sed_read.f90`) can now be written
with `count(...)`; a byte-identity control is the test.
