### Stage A: a reliable numerical step (immediate)

**N0. Harness baseline** (A). Run

**N1. Trust-region radius (R1)** (W; `steady_newton.f90`
`solve_steady_jfnk`, `dogleg_step`, `trust_region_step`).
- `pgmres` returns a named outcome (converged / truncated / breakdown /
  nonfinite), the achieved relative residual and the step norm; the
  initialization reads them.
- The radius is initialized from a finite descent direction: the Krylov
  step when it exists, else the projected gradient direction; a positive
  dimensionless lower bound tied to the variable scales `D`.
- `tr_dmax` is not fixed for the whole solve by the first step; the
  radius may grow past it on an adequate model, within the feasible set.
- No direction at all is a reported failure with the linear/model reason;
  the loop does not repeat zero-radius iterations.
Acceptance: harness rows "zero first direction then a direction",
"nonfinite initialization", "tiny valid first direction", "zero residual
state"; `wasp_full_newton` bitwise (the atomic three-unknown route never
takes a zero first direction); one short restart of the B5m reproducer
reporting the first two iterations' radius and direction status.

**N2. Cauchy length (R2)** (W; `trust_region_step`).
- With `g = B^T r` (band) and `Ag = A g`, the length is the line minimizer
  along the direction actually used, `tau = (r . A g) / ||A g||^2`, taken
  only when `r . A g > 0`; the point is named an approximate descent
  point, not an exact-gradient Cauchy point.
- When the direction ascends, a direction with a verified decrease is
  produced or model failure is reported; dropping the leg alone is not
  called a guarantee.
- The predicted decrease is recomputed for the projected step (kept from
  B5j/B5l) and the Krylov leg's achieved residual is checked before its
  reduction is assumed.
- The source comment defending the old length by B5e's convergence is
  removed with the length.
Acceptance: harness row `r = 1, A = 1, B = 10` (merit 0.5 to 0 at the new
point); exact-gradient case unchanged; negative slope, truncated Krylov
leg, active bound, line minimum beyond the radius; `wasp_full_newton`
measured (the atomic route uses the Cauchy leg on the coupled default, so
movement is possible and is reported, not assumed away).

**N3. `pgmres` breakdown (R3)** (W; `pgmres`).
- A vanishing next basis vector is Arnoldi termination only if the reduced
  system is nonsingular; rank is checked before triangular division; a
  singular or inconsistent reduced system returns the named breakdown or
  a safe least-squares solution.
- LAPACK status and finiteness are checked after every preconditioner
  application and on the returned step.
- The true scaled linear residual is verified when convergence is claimed
  at breakdown or the reduced system is nearly singular.
- Reorthogonalization only if a measured loss warrants it (report the
  loss first).
Acceptance: identity operator returns one; zero operator returns the
named breakdown, a finite step and a true residual; the outer loop
reports the outcome by name; `wasp_full_newton` bitwise.

### Stage B: the constrained residual (high)

**N4a. One elemental constraint map** (W; new module beside
`diffusive_photochemistry.f90`; readers in `steady_newton.f90`
`freeze_species_unknown_box`, `eval_residual`,
`write_species_rows_into_composition`; `carrier_element_headroom`).
- The stoichiometric map from the carrier set to element inventories is
  written once: `2 n(H2) + n(H+) + n(OH) + 2 n(H2O) <= nH_avail`,
  `n(OH) + n(H2O) + n(CO) <= nO_free`, `n(CO) <= nC_free`, with the
  eliminated molecular ions and HeH+ placed on the side the closure fixes
  them on.
- Feasibility of a candidate state is evaluated from that map at every
  candidate, by violation magnitude, not by a count of violating cells.
- `carrier_element_headroom` keeps its box sides as derived quantities of
  the map; the B5l finding that OH/H2O hold hydrogen their headroom does
  not mention is closed by the map.
Acceptance: `steady_species_rows` rows: H2 and H+ at their separate
ceilings is infeasible (inventory two against one); every regression
carrier set is feasible at its golden state; `mol_carrier`,
`mol_diffusion` marching bitwise (the map only reports on the marching
path).

**N4b. A step that moves along the constraint surface** (A design memo,
then U, then W). The frozen box excludes directions along a shared
budget and freezes ceilings that depend on the density and element
unknowns (both Newton unknowns). Two routes: (i) a linearized constraint
set from the map's derivatives (including `dn/d ln n = n`) with a
projected or active-set step on it and an explicit restoration phase for
an infeasible start; (ii) a parameterization that conserves elements by
construction (independent degrees of freedom, trace and zero abundances,
a consistent Jacobian). Route (ii) changes the unknown layout and is
presented to the user before any code. The B5l comparison is repeated at
one saved state with violation magnitude, actual merit reduction,
achieved linear residual and elapsed time, not iteration counts.

**N5. Residual reproducibility contract** (W; `steady_newton.f90`
`eval_residual`, `ionization_equilibrium.f90` seeds). Repeated `F(Y)` at
one `Y` with different admissible fast-chemistry seeds must agree within
a measured budget of the outer residual; the test states the budget and
is RED where B5h found retention 0.77. The diagnostic beside it: chemical
decay rates from the reaction Jacobian with the conservation modes
removed, against the advective and diffusive times on the resolved
gradient length (not the cell width). Outcome decides whether the slow
mode is promoted into `Y` (H2 transported, as now) or the closure is
tightened; no fast intermediate is promoted by default.

**N8. Base amplification and the two provisional tolerances** (W then A).

an imposed reservoir condition and use that equation in residual and
Jacobian alike; differentiate through composition, particle count,

directional-derivative error against perturbation size and inner
tolerance at the base; set the inner tolerance from the measured map from

not a bound where the boundary amplifies). `cert_tol_carrier` and

**N6. Two ionization-front roots: branch study** (W diagnostics, A
interpretation, U on the outcome). Ordered sequence from review 5.2: (1)
