# P5b: the executable a test selects, and the executable a test says it ran

PLAN_20260919_rev1 item P5b; PLAN_20260919_review section 7.3. Written
2026-09-19 (KST). Every number below is MEASURED by a run recorded here or
READ from the file named.

## Verdict

The defect was real and is closed. Before this item no suite under
`src/tests/` printed or checked the identity of the binary it ran (READ: the
string `md5` does not occur in any pre-change suite script except where an
OUTPUT file is hashed), and the selection was made by four different names:
`EXHALE_EXE` in nine suites, `EXHALE_RESID_EXE` in the two
residual-determinism scripts, `EXHALE_SPECIES_EXE` in `species_face_flux`
and `steady_species_rows`, `EXHALE_COUPLED_EXE` in `coupled_source_step`,
and a positional argument in `run_seed_independence.sh`. A run that set
`EXHALE_EXE` and reached `residual_determinism` was answered by the tree's
own build, silently (MEASURED, below).

`EXHALE_EXE` is now the one name. The others are accepted aliases with a
stated precedence, a pair that names two different files is refused rather
than resolved, and every suite that runs the binary prints its path and md5
and asserts that the file it is about to run has the md5 that was asked for.

## The policy, in one place

`src/tests/exhale_exe.sh` carries it and the other scripts point at it.

- `EXHALE_EXE` selects the binary. Unset, the binary is `$ROOT/EXHALE.x`.
- `EXHALE_RESID_EXE` is an accepted alias everywhere, not only in the
  residual-determinism scripts. `EXHALE_SPECIES_EXE` and
  `EXHALE_COUPLED_EXE` are accepted aliases in the three suites whose
  whole-binary rows they also switch on; in those suites the rows run when
  `EXHALE_EXE` or the suite's alias is set, and are skipped when neither is.
- Precedence: when several names are set and resolve to the SAME file the
  run proceeds; when they resolve to DIFFERENT files the suite prints one
  `FAIL <suite>_binary_selection measured=conflicting_request` row and exits
  1. Nothing is chosen silently.
- A binary named on the command line (`run_seed_independence.sh <binary>`)
  is a request of the same kind, and a variable that disagrees with it is
  refused the same way.
- Identity: before anything runs, the suite prints

  ```
    binary: <path>
    binary md5: <md5>
    binary selected by: <which name, in words>
  PASS <suite>_binary_identity measured=<md5> reference=<md5> tol=0
  ```

  and a suite that copies the binary into a working directory asserts the
  md5 of the COPY, which is the file that executes.
- `EXHALE_EXE_IDENTITY_ONLY=1` makes a suite state its identity and stop
  without running anything. It is what the sentinel suite reads.

## The sentinel: `src/tests/executable_identity/run.sh`

The suite copies `EXHALE.x`, appends bytes past the end of the ELF image so
that the copy has a different md5 and the same program, points `EXHALE_EXE`
at the copy and requires each suite to report the COPY. A suite that ignores
the request reports the tree's md5 and fails. Twenty-one rows: thirteen
suites, the default, the alias alone, two agreeing names, a refused
conflicting pair, the command-line argument and a name refused against it.

MEASURED 2026-09-19, tree binary md5 `2c3b0acc9983aec03bb4f844294fed18`,
sentinel copy md5 `debf0614d705b267ac913c1806916c9c`: 21 rows, 0 failing,
in under one second (no row executes the binary).

## RED and GREEN

**RED, the selection** (MEASURED, the pre-change scripts staged from HEAD in
a scratch mirror whose `EXHALE.x` is a symbolic link to the tree's):
`EXHALE_RESID_EXE=/nonexistent/EXHALE_notthere.x` gives, at once,
`FAIL residual_determinism_binary measured=missing reference=/nonexistent/EXHALE_notthere.x`,
while the same path in `EXHALE_EXE` is not refused at all: the suite goes on
and evaluates with the tree's binary, and its output never names the file
that ran (0 lines matching `binary md5`, 0 naming the requested path).

**GREEN, the same request on the delivered suite**:

```
  binary: /nonexistent/EXHALE_notthere.x
  binary md5: missing
  binary selected by: EXHALE_EXE, naming one file
FAIL residual_determinism_binary_identity measured=missing reference=missing tol=0
```

and exit 1: the binary that was asked for is not there, and no other binary
is substituted for it.

**RED, the identity** (READ): no pre-change suite script contains an md5 of
its binary. **GREEN**: the thirteen sentinel rows above.
