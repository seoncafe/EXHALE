Figures for `docs/lower_atmosphere_coupling.tex`, regenerated by
`python3 make_figures.py` (matplotlib, usetex off).

- `fig_lc_planets.pdf`    — Tier-1: equilibrium q_H2(1 ubar; T) + 4-planet base-radius brackets
- `fig_mol_structure.pdf` — Tier-2 gates: H2->H fronts (HD209458b / hot Uranus), T, molecular species
- `fig_vulcan_vs_eq.pdf`  — Tier-3: VULCAN photochemistry vs chemical equilibrium (HD189733b)
- `fig_w52_he10830.pdf`   — WASP-52b He 10830, old vs corrected base radius
