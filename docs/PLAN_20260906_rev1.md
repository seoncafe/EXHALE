## 3. Execution order (rev 1)

Roles as before: the advisor writes briefs and verifies diffs and tests;
workers implement; the user decides where a row says so. Every code step
carries its test (RED before, GREEN after) and a scoped impact measurement on
the paths it touches; a golden refresh only at the end of a series, reported.
Labels: **A** acceptance contracts and run modes, **B** target system and its
implementation, **C** spectra and configurations, **D** validation.

### Step A. Acceptance contracts and run modes (before Phase 3 physics)

**A0. Run-mode contract** (advisor writes, user accepts; a short document).
Three states of a run: initialization/continuation (non-root iterates
allowed as numerical guesses; no physical time, budgets or histories
accumulate), physical integration (every accepted step satisfies its
discretized equations or a justified fast-process closure within its stated
validity), certified stationary solution (A2 gates on the exact written
state). The handoff from initialization: an admissible, source-consistent
state, caches rebuilt from it, or a stated failure. Diagnostic snapshots
(the fixed-step `mol_*` cases) are labeled as relaxation states, never
certified as physical transients, and a valid finite-time state is writable
without a zero stationary residual. Class 4 lives only in initialization
mode.

**A1. Status and classification contracts** (workers, disjoint files).
- Carrier solve: acceptance is on the RETURNED state, every unconstrained
  row, absolute or physically scaled floors, regardless of the termination
  branch (`converged`, `accepted_at_floor`, limiter applied afterwards);
  the relative-drop branch stays as a diagnostic; constraint activity is
  recorded by cell and never certifies a failed row. Tests: successful raw
  status followed by an active limiter; failed raw status with a
  constrained worst cell and an unacceptable unconstrained row; a large
  relative drop with an unacceptable final residual; non-finite rows; an
  otherwise valid constrained state.
- Acceptance classes: one meaning for every consumer (`steady_newton`, the
  streak logic, the reports); a class-5 root has the same validity as a
  class-1 root; a class-4 state cannot pass any final acceptance. Tests:
  equivalent roots through classes 1 and 5 get the same verdict; a genuine
  class-4 state is refused.
- Gate: scoped impact measurement. Byte identity is expected only where
  inspection shows the changed branch unused (no class-5 cells in the
  trial history, no `accepted_at_floor` or post-limiter acceptance in the
  run); every change recorded and explained; no tolerance chosen to keep a
  snapshot.

**A2. Independent final certification** (advisor design with B1a's
inventory, one worker).
- Inputs: the active-equation inventory (B1a): each independent transported
  carrier balance (H2, H+, and OH/H2O/CO when the oxygen network is on), the
  active elemental transport balances (He/H partition, trace elements when
  enabled), the algebraic closures only for species eliminated by a
  justified fast process, the mass, charge and energy conditions, the
  boundary equations by cell class, and the model-validity flags (CO
  ceiling active, oxygen energy ledger incomplete, out-of-domain closure).
- The steady equation of a transported species is transport minus
  reaction; a nonzero reaction source is not a failure.
- Evaluation status per equation (not applicable / evaluated / unavailable
  or invalid); finite values required; an active but unevaluated equation
  cannot pass. The evaluator is side-effect-free or runs in an isolated
  workspace; it never re-equilibrates a transported partition to measure
  it; the thermodynamic and radiation backgrounds it uses are those of the
  state being certified.
- Norms: one condition per active independent balance, units and floors
  stated, a local safeguard at fronts and thin layers; the combined `rvol`
  ratio is reported, not decisive.
- The marching caller's `.false., 0.0d0` carrier condition and the trial
  count of uncertified cells are replaced by this evaluation.
- Tests: active carrier model with `bg_ready` false (status unavailable,
  never a pass); an inactive model (not applicable); stale background after
  a state change; repeated evaluation with output on and off preserves the
  state; a small-rate species with a large fractional imbalance beside a
  balanced dominant one is caught; oxygen carriers, H+ transport and active
  element diffusion all evaluated.

**A3. Carrier-only rejection and retry** (after A1, A2 and the carrier
checkpoint).
- First the checkpoint: the carrier-local state A3 mutates (carrier
  fractions, saved backgrounds, photolysis arrays, advection corrections,
  row scales, headroom, constraint diagnostics, the cumulative CO record) is
  enumerated and its restore tested.
- Then the controller: on a failed returned-state acceptance, restore,
  halve the carrier substep with the background explicitly frozen (which
  coefficients stay frozen and which follow the carrier state is stated),
  cover the original interval with accepted substeps, bounded retries and a
  dt floor, then stop with the reason; the entry state or a clearly marked
  partial diagnostic state is what survives a permanent failure, never a
  report that the interval was completed. Rejected trials never enter the
  accepted CO record or the step statistics. Labeled partial recovery.
- Tests: injected failure after an accepted substep and after counter and
  cache mutation; complete restoration; correct elapsed interval; agreement
  with an explicitly subdivided integration; temporal refinement at fixed
  end time shows the expected order (R10).

### Step B. Target governing system and its implementation (Phase 2 and 3)

**B1a. Active-equation inventory** (advisor, short, first): the list A2
consumes, per configuration flag. Written before A2 is coded.

**B1. Target specification** (advisor writes, user accepts; the Phase 2
gate). Separate from the D0 audit; for every C-item a target equation, an
owner, an acceptance test. Contents (rev 3 section 4.2 with the review's
positions adopted): thermal plus kinetic energy as the evolved variable with
an explicit formation/excitation ledger and a conservative coupled
temperature-composition solve; the temperature-preserving pressure reset
removed as an independent update; chemistry preserves the supplied density,
reconstruction a check only; the independent species space and constraints
and the constrained Jacobian on it; a derived ambipolar closure with charge
neutrality and a stated current condition, the common-velocity
approximation only within a quantified regime; the CO model or exclusion
with the cumulative record as the observable; the H2 internal-energy
convention shared by EOS and chemistry; the H3+ emission model from the
published fit definitions with its density and temperature domain; the
oxygen energy ledger or exclusion; `_adv` products on the same source
assembly or refused; Lyman-alpha excitation loss and de-excitation return
derived together under local energy ownership; boundary constraint count and
the boundary equations by cell class; the rollback contract, i.e. the
enumerated checkpoint of the whole attempted step; the verification matrix
(closed reacting cell, two-cell radiation exchange, returned-temperature
residual, species stationary residual, invariants, temporal refinement,
splitting order).

**B2. Residual-controlled temperature solve.** Bracketed or safeguarded
iteration, sources evaluated at the returned temperature, final residual
test. An unacceptable update returns a failure status and the run stops
safely; no recovery is claimed until B3a. A temperature floor is either a
physically specified reservoir with its heating budgeted, or a failure; a
recorded but unbudgeted floor does not pass. Tests: falling cooling branch,
strongly temperature-dependent heating, unavailable bracket, floor
encounter.

**B3a. Attempted-step controller** (the whole update: hydro, diffusion,
carriers, radiation and chemistry, energy) with B1's checkpoint: save,
trial, evaluate (positivity, element and charge constraints, equation
residuals, energy budget), adopt or restore and shorten, stop with
diagnostics after the retry limit. Accepted-step statistics exclude rejected
trials. Tests: mutated trial fully restored; elapsed time correct; no
rejected contribution in any accumulated record.

**B3b. Rates, energies and thermodynamics the source step needs** (rev 3
Phase 3 increments, each with its test): photoevent energy partition
including the H2 channels and excited recipients; reaction heats including
the oxygen and associative channels or their exclusion; the common H2 state
model and consistent thermodynamic functions; the H3+ absolute emission
model with joins and domain; finite-rate evolution of species not
legitimately eliminated (an explicit increment, not replaced by solving all
species in equilibrium). Independent tests against analytic limits,
conservation identities and published data within their validity ranges,
not only against the shared assembly.

**B3c. Coupled species-energy source step and the final-state assembly
contract.** One solve for temperature and composition under the energy
constraint; the pressure reset removed; chemistry mass-preserving. One state
and one source evaluation feed certification and every output file; the
diagnostic recomputation of `write_heat_breakdown_eq` and the
`excited_H_update` before the final write are replaced by that assembly or
shown not to mutate the certified state. `output_state_consistency` turns
GREEN as one of several checks. Temporal refinement and splitting-order
tests at fixed end time. Goldens refreshed once at the end of this series.

**B4. Conservative spatial operator** (rev 3 Phase 4): species face fluxes
consistent with the mass flux, thermal and chemical energy transport with
the same face fluxes, the charged closure and the background response for
diffusive mass conservation, the hydrostatic residual and boundary
constraint count implemented and tested for the active system. Tests:
diffusion-only column; reacting transport balance; mass, elements, the
stated current condition and material energy closing with consistent face
fluxes.

**B5. Stationary equations on the same terms** (rev 3 Phase 5): species
rows for every active transported balance on B1's independent space (no
redundant mass, element and species rows), the same source assembly as the
marching step, A2 as the acceptance, Jacobian-action checks, inner-solve
determinism, reload and acceptance consistency. `Ionization transport` with
`Solver: Newton` becomes supported by derivation or stays refused with the
reason. Direct Newton support is optional for a configuration whose
time-converged solution passes A2 independently.

**B6. Validity diagnostics** (rev 3 section 4.2 last item): the flags A2
reads (CO ceiling active, oxygen ledger incomplete, out-of-domain closure,
floor hits) printed with every final state and carried into the output
headers.

### Step C. Spectra and configurations (data preparation independent of A and B; consumer tests re-run after source changes)

**C1. Loaded-field semantics and consumer validation.** State whether table
values are point samples or bin averages and reconstruct accordingly; test a
narrow line, a sharp threshold, a coarse bin and a steep continuum through
the production photoionization, heating and Balmer consumers; require rate
convergence with resolution; compare band energy and photon number of the
grid against the source table; include the 10 A upper cutoff in every
integrated XUV comparison. Coverage tests derived per configuration from
the active threshold inventory (2600 A metastable; 3647 A when both
`Stellar Teff` and `Stellar radius` arm the H(n=2) coupling; the lowest
active metal), with labels matching the bands computed. The hot-Uranus
stand-in table (to 2995 A) does not cover the full required Balmer
continuum; the production guard stops such a run, and the inventory says so.

**C2. WASP-121 b candidate C.** Solar XUV below 1700 A at the chosen 1.6e6
normalization, the scaled WASP-17 photosphere above, no renormalization of
either component to force continuity, the join ratio reported; header:
provisional composite, proxy photosphere, XUV normalization as chosen (not a
Huang reproduction). The He 2^3S photoionization rates of A, B and C through
the production integrand on one prescribed state and attenuation, reported
as sensitivity; the transit consequence only in D.

**C3. Configuration switches**, one at a time, each after its C1 checks:
purpose, reference model, SED file and checksum, coverage, units at the
orbit, distance and normalization assumptions, active absorbers and dilution
in the folder README; previous outputs kept and labeled with their input.
HD 189733 b: the Salz-normalized file for the Salz comparison; the Bourrier
file, visit stated or the B-E mean with variability as an input uncertainty,
for the observed-star model. WASP-121 b: C, provisional. HD 209458 b: the
WHI 2008 file. `VULCAN/atm/stellar_flux/sflux-HD189_B2020.txt` untouched.

### Step D. Validation (instruction-gated, split by purpose)

**D-diagnostic.** Bounded development runs, explicitly requested, may run at
any time; they carry their known limitations in the header and are never
presented as validated predictions.

**D-physical.** A configuration enters physical validation only when every
gate its active model needs has passed: A0 to A3 always; B2, B3a to B3c for
any configuration with molecular or metal sources; B4 for any configuration
that transports species or elements; B6 flags clear (or the run is
excluded); C1 and C3 for its input field. Atomic configurations proceed
without unfinished oxygen work when oxygen is outside their active model.
Direct Newton (B5) is not required where a time-converged solution passes A2.

**D-comparison.** A published reproduction additionally requires matched
boundary conditions, geometry, composition, rates and spectral assumptions,
or an explicit list of the unmatched terms (the like-for-like rule of
2026-09-05).

**D-figures.** Paper and poster figures last, and only on explicit
instruction.

## 5. Minimum test matrix (from the review's section 7, adopted)

| Target | Focused test | Acceptance |
|---|---|---|
| A1 returned state | successful raw solve then limiter; failed raw solve with constrained worst cell; large relative drop | every returned-state condition passes or the update is rejected |
| A1 classes | equivalent roots via classes 1 and 5; genuine class 4 | validity from the requested equations, not the solver that found the root |
| A2 inventory | oxygen carriers, H+ transport, active element diffusion | all required balances evaluated; no row silently absent |
| A2 readiness | active carriers with `bg_ready` false | explicit unavailable status, never an initialized zero |
| A2 norm | small-rate species with large imbalance beside a balanced dominant one | not hidden by the combined sum |
| A2 state identity | repeated certification around optional output calls | same state and fields |
| A3 rollback | failure after accepted substep and after counter/cache mutation | no rejected contribution; correct completed interval |
| B2 thermal | falling cooling branch; strong heating dependence; no bracket; floor | final residual, admissibility, defined failure |
| B3 sources | closed reaction; isolated photon event; recombination; two-cell exchange | thermal plus chemical/excitation/radiation accounting closes |
| B3 time accuracy | successively smaller steps to one end time | temporal convergence and controlled splitting error |
| B4 operator | diffusion-only column; reacting transport balance | mass, elements, current condition, material energy close |
| B5 stationary | time-converged reference; Jacobian action; reload | same equations and acceptance on the independent space |
| C1 coverage | triplet, low-IP metal, active Balmer configurations | correct endpoints and labels; uncovered bands refused |
| C2 SED | A/B/C through one production rate at a fixed state | differences reported as sensitivity |
| Output | main fields and derived products | one identified state and model; certified, transient and diagnostic products distinguished |

Tolerances, units and floors are set in each implementation brief; none is
chosen to preserve an existing snapshot or convergence label.
