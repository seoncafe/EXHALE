## 1. The two verdicts

**L20 is NEGATIVE as posed: the `cool` column of a state the current code
writes IS the cooling of that state.** The 0.35 to 0.76 ratio reported in L18
section 7 was measured on `backup/regression/wasp_full_newton/IC/`, the pair
the `grid_and_gates` restart row reads -- and that pair was PINNED on
2026-09-08 from git `35d9dd5d3ca7`, an earlier code generation, not written by
the code under test. Its own `IC/README.md` says it is refreshed only together
with the golden. Measured on every state the current code produces, the `cool`
column and the total of `Cooling_breakdown.txt`, which recomputes every channel
from the written (T, rho, f_sp), agree to between **3.4e-15 and 3.0e-10**.
What was actually wrong is that nothing asserted it: the same statement had
been asserted for `heat` since the H(n=2) closure-lag incident and never for
`cool`, which is how a pinned state 1.8x out could sit in the suite unnoticed.
The assertion is added; no physics changed.

**L19 is POSITIVE and is fixed.** The composition a sweep returns is now put on
the density the sweep was given, one factor per cell, and the mass closure
`max_j |sum_i f_i A_i - 1|` of a state is reported by the certification.
Measured on the written state of two marching cases, the closure falls from
**4.15e-14 to 4.20e-16** (`hp_front`, 100 steps) and from **1.54e-14 to
3.62e-16** (`hydrostatic_column`, 300 steps) -- from a quantity that ratchets
with the number of sweeps to one that sits at the rounding floor.

## 3. L19: the mass closure

### 3.1 What it is, and why it drifted

The mass fractions of a state are `f_i = n_i m_i / rho`, so
`sum_i f_i A_i = 1` is the DEFINITION of `f_sp` and not a tolerance. The sweep
holds the density fixed -- since T2.1 it is an input the sweep may not write --
and solves the chemistry cell by cell; what it returns weighs that density only
to the arithmetic of the cell solves. The element totals come back conserved to
about 4.4e-16 and the mass is a weighted sum of them, so every sweep leaves the
closure off by a few units in the last place, and in the same direction.

Nothing measured it and nothing bounded it. The element operator's own test
(`element_mass_closure_tol = 1e-10`, `binary_element_diffusion.f90`) compares a
step's closure with the ENTRY closure of that step, four decades above the
increment and blind to a monotone drift by construction; the certification
inventory had no entry for it. Item L18 measured where that ends: about 1e-14
per outer pass of a stationary solve, 5.1e-13 after nineteen passes and 6.2e-13
after twenty-four, which is the state a restart then has to choose a density
from.

### 3.2 The rule

**The density is the conserved quantity and the composition is the partition on
it**, so the composition is put on the density and never the other way round.
Immediately after the sweep, and before the heating and the cooling are
contracted with it, every species density of a cell is multiplied by the single
factor that makes the mixture weigh the density the sweep was given. Every
element ratio, every ionization split and every metal-to-hydrogen ratio survives
a common factor untouched; only the normalization moves, and it moves by the
closure departure, which is one part in 1e16.

It is the same rule `load_IC` applies to a restart file (item L18), so a state
written, read back and re-measured now passes through one projection and not
two different ones. Default ON; `EXHALE_MASS_PROJECTION=0` restores the
unprojected composition for a control experiment.

### 3.3 The closure is now reported

`certification_evaluate` measures `max_j |sum_i f_i A_i - 1|` over the physical
cells from the same (u, f_sp) every row is measured on, with `calc_rho` as the
mass policy so no second mass table exists to drift from it, and the report
prints it with its worst cell:

```
   mass closure of the composition, max |sum_i f_i A_i - 1| =  4.409E-16 at cell 210, r =   1.17749
     reported only: the sum is one by the definition of the mass fractions, so this is the arithmetic of the state and no equation of it
```

REPORTED AND NEVER GATED. It is a statement about the consistency of the two
halves of a state, not an equation the state has to satisfy, and its natural
scale (1e-16) is nine decades below every tolerance in the inventory.

### 3.4 What it does, measured

The mass closure of the state a run writes, control against measured, one
thread, same case, same step cap:

| case | what it runs | control | measured |
|---|---|---|---|
| `hp_front` | 100 marching steps | 4.151e-14 | **4.196e-16** |
| `hydrostatic_column` | 300 marching steps | 1.537e-14 | **3.623e-16** |
| `.L14/x002_HeH2.13` | 8 outer passes of a stationary solve | 2.208e-14 | **2.706e-16** |

and on a stationary evaluation of a certified state the report reads 4.4e-16.
The drift is gone: what is left is the rounding of the projection itself. The
stationary-solve row is the one item L18 traced to 5.1e-13 over nineteen passes
and 6.2e-13 over twenty-four; eight passes of the same solver leave 2.2e-14
without the projection and 2.7e-16 with it, so the increment each pass added is gone
and not merely smaller.

## 7. The Codex review of 2026-09-15, applied to L19

**The projection was unbounded, and an unbounded renormalization is a way of
making a broken closure invisible**: whatever the cell solve did to the mass,
the composition would come back weighing the density exactly and nothing would
say it had been moved. The factor is now measured and has two thresholds:

| `max_j |s - 1|` | what happens |
|---|---|
| <= 1e-12 | the rounding of the cell solves, which is what the projection exists to remove; silent |
| 1e-12 to 1e-8 | projected, and reported loudly with the cell |
| > 1e-8 | **NOT projected.** A closure error of that size is a failure of the sweep and is reported as one; the composition is handed back as the solve left it, so the certification's own mass-closure line shows the failure instead of a projection hiding it |

The factor is refused the same way where it is not a usable number at all -- a
non-finite or non-positive mixture mass is not a composition, and multiplying by
it would put the NaN into every species column. Both refusals are counted
(`n_ieq_mass_projection_refused`) and the largest factor the run ever applied is
kept (`ieq_mass_projection_worst`).

**What the projection moves is reported with it**: every element total moves by
exactly `|s - 1|` in ABSOLUTE nucleus density, because the factor is common to
every species -- which is why no element RATIO moves at all, and why the ratio
is the wrong thing to report here.

On the certified LHS 1140 b state the factor is 4.4e-16 and the projection is
silent, as it should be.
